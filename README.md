## FF-A Reference Test Secure Partition

```text
This is a purpose-built Secure Partition running under Hafnium (i.e. SPMC at S-EL2) 
implementing FF-A endpoint, services, and Virtio Message Bus over FF-A protocol. 
This SP is being built for Linux Driver Development, protocol validation of FF-A,
and virtio-msg-ffa, as the Arm specification for the same evolves.
```
